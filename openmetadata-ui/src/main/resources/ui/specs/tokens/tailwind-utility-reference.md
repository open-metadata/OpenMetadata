# Tailwind utility reference

> Generated by `node scripts/design-tokens/gen-tailwind-reference.js` from `globals.css`. The go-forward styling system: UntitledUI components + Tailwind (`tw:` prefix). Never hardcode a value — use these utilities. The Antd/Less `--om-*` layer ([token-reference.md](./token-reference.md)) is legacy.

## Semantic color utilities (prefer these — they adapt to dark mode)

**Background:** `tw:bg-primary`, `tw:bg-secondary`, `tw:bg-tertiary`, `tw:bg-quaternary`, `tw:bg-disabled`, `tw:bg-overlay`, `tw:bg-brand-primary`, `tw:bg-brand-solid`, `tw:bg-error-primary`, `tw:bg-warning-primary`, `tw:bg-success-primary`

**Text:** `tw:text-primary`, `tw:text-secondary`, `tw:text-tertiary`, `tw:text-quaternary`, `tw:text-disabled`, `tw:text-placeholder`, `tw:text-white`, `tw:text-brand-primary`, `tw:text-error-primary`, `tw:text-warning-primary`, `tw:text-success-primary`

**Border:** `tw:border-primary`, `tw:border-secondary`, `tw:border-tertiary`, `tw:border-disabled`, `tw:border-error`, `tw:border-brand`

**Foreground:** `tw:text-fg-brand-primary`, `tw:text-fg-error-primary`, `tw:text-fg-warning-primary`, `tw:text-fg-success-primary`
