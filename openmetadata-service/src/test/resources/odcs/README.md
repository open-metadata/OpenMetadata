# Published ODCS schema regression fixture

`odcs-json-schema-v3.1.0.json` is an unmodified copy of Bitol's published ODCS v3.1.0 schema:
https://github.com/bitol-io/open-data-contract-standard/blob/v3.1.0/schema/odcs-json-schema-v3.1.0.json

SHA-256: `2cb7dd6fe43344d2233e0406438622681dc3ebadcf8f0d606a15b40c8f6752c0`.

The upstream Apache-2.0 license is included in `LICENSE.txt`.
The fixture is local so conformance checks do not depend on a network service or the evolving latest schema.
